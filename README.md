# config-converter

Teaching CLI built with **Launchpad** (idea → GitHub → CI/CD → npx).

```bash
npx @tufayl/config-converter fixtures/sample.conf -o out.xml
# or from a local tarball:
npm install ./tufayl-config-converter-0.1.0.tgz
npx config-converter fixtures/sample.conf -o out.xml
```

Repo (workshop): `github.com/TufaylAhmed/config-converter`
